# spongycode Homebrew Tap

Official Homebrew tap for [spongycode](https://github.com/spongycode) macOS applications.

## How to Install

```bash
brew tap spongycode/tap
brew install --cask clap
```

## Included Casks

| Cask | Description |
| :--- | :--- |
| **clap** | Local-first macOS clipboard & shell history manager |
